# Metanoid

Metanoid is my take on the classic brick-breaker formula, inspired mostly by **Arkanoid**

The main point of the game isn't a collection of handcrafted levels. It's the procedural engine behind them.

Every level is generated on the spot: its layout, brick sizes and types, colors, biome, difficulty, power-ups, special effects, modifiers, and eventually boss stages. Nothing is manually designed, so the game can keep creating new levels forever while gradually becoming harder and introducing stranger combinations.

The goal is to make every run feel familiar, but never exactly the same.

Built in pure Rust.

## Running

```bash
cargo run
```

The project is still early and changing quickly.
